Part 3 — Glossary

Term Emoji Plain definition Recipe tickler (tiny prompt → output file)
AI Asset 💎 Any reusable artifact produced with AI, such as a prompt, spec, app, dataset, or memory file. "List my AI assets from this chat as a table → assets.md"
AI Pair Programming 👥 A human sets intent and reviews while an AI drafts, explains, and refactors code. "Pair with me: build a one-file app from this spec → app.html"
Agentic Workflow 🤖 A multi-step process in which an AI plans, uses tools, and checks its own work. "Plan the steps, run them, and log each result → run_log.md"
Hive Mind (Distributed) 🐝 Many specialized agents that share memory and coordinate toward one goal. "Design 5 agent roles plus a shared memory schema → hive.json"
Progressive Intelligence 📈 Capability that improves with every run because outputs feed back in as assets. "Compare v1 and v2 outputs and list the gains → delta.md"
Longitudinal Intelligence 🕰️ Insight drawn from data and memory tracked over time. "Build a timeline of events from these notes → timeline.csv"
AIOps 📡 Using AI and telemetry to run, monitor, and repair IT and AI systems. "Summarize these logs into incidents → incidents.md"
Telemetry 📶 Logs, metrics, and traces emitted by running systems. "Turn this log into a metrics chart → metrics.html"
Semantic Memory 📚 Stored facts and concepts that are true regardless of when they were learned. "Extract the facts as key–value pairs → facts.json"
Episodic Memory 🎞️ Stored events and sessions: what happened, when, and with whom. "Log this session as dated episodes → episodes.md"
RAG 🔎 Retrieval-augmented generation: fetch relevant chunks first, then answer. "Chunk this document and cite chunks in answers → rag.py"
Chroma 🟣 An open-source embedding database often used for RAG. "Write a Chroma ingest-and-query script → chroma_rag.py"
Embedding 🧭 A numeric vector that represents meaning, so similar text sits close together. "Embed these lines and plot them in 2D → embed.html"
Context Window 🪟 The amount of text a model can consider at once. "Crop this to under 500 words, keeping the key facts → crop.md"
Distill / Merge / Crop ✂️ Minimize memory: keep the essence, join overlaps, and trim to fit. "Distill, merge, and crop these notes → memory.md"
Markdown Spec 📝 A structured Markdown document that tells an AI exactly what to build. "Write a spec with headings, tables, and acceptance tests → spec.md"
Prompt Pattern ♻️ A reusable prompt template with slots for role, inputs, and outputs. "Make a fill-in-the-blank prompt template → prompt.md"
Constraint-Based Modeling 📦 Defining a solution by its limits and rules before its features. "List the hard and soft constraints as nested bullets → constraints.md"
Nested Boundaries 🪆 Constraints layered from system level down to function level. "Draw the nested boundaries as SVG boxes → bounds.svg"
First Principles ⚛️ Reasoning from basic truths instead of from analogy. "Reduce this process to its minimum steps → steps.md"
Asymptotic Reduction 📉 Removing parts and steps until further removal would hurt quality. "Cut steps until the output breaks, then list them → reduce.md"
Regions (code) 🗺️ Named, foldable blocks that organize a large single file. "Refactor into named regions with a table of contents → app.py"
Streamlit 🎈 A Python library that turns scripts into web apps. "Make a Streamlit app with a sidebar and a chart → app.py"
Single-File App 📄 An entire app (HTML, CSS, and JS) in one shareable file. "Build it as one self-contained HTML file → index.html"
GitHub Pages 🌍 Free static hosting from a GitHub repository. "Write a Pages-ready index and README → index.html"
GitHub Actions ⚙️ GitHub's built-in automation (CI/CD) triggered by repository events. "Write a Pages deploy workflow → .github/workflows/static.yml"
VBF 📏 Vital Business Function: a business process so critical that its outcomes define the value and efficacy you measure. "Define the VBFs with metric, baseline, and target → vbf.csv"
Value-Based Care 💰 A payment model that rewards health outcomes instead of service volume. "Map features to outcome metrics → value_map.md"
CMS Age Groups 👪 The 12 CMS-HCC risk-adjustment age bands: 0–34, 35–44, 45–54, 55–59, 60–64, 65–69, 70–74, 75–79, 80–84, 85–89, 90–94, 95+ (each split by female/male into 24 age-sex cells). "Make an age-group table with order, label, and emoji → age_groups.csv"
Model Drift 📉 A change in model behavior or accuracy over time or across versions. "Rerun the golden set and diff the results → drift.md"
Model Qualification ✅ Testing a model against your own tasks before trusting it. "Score 3 models on these 10 prompts → scores.csv"
SWOT 🧭 Strengths, weaknesses, opportunities, and threats. "Make a SWOT for Web, Python, and Azure → swot.md"
Steel Man / Straw Man 🛡️ Arguing the strongest (steel) versus the weakest (straw) version of a view. "Steel-man and straw-man this decision → debate.md"
MCP 🔌 Model Context Protocol: an open standard for connecting AI apps to tools and data. "Describe an MCP tool schema for this API → tool.json"
A2A 🤝 Agent2Agent: an open protocol for agents to discover and talk to each other. "Write an agent card for this agent → agent.json"
WebRTC 📡 A browser standard for real-time peer-to-peer audio, video, and data. "Build a two-person video call page → call.html"
PeerJS 🧷 A JavaScript library that simplifies WebRTC peer connections. "Use PeerJS for multiuser chat → peer.html"
STT / TTS 🎙️ Speech-to-text and text-to-speech. "Transcribe the mic and read replies aloud → voice.html"
MediaPipe 🖐️ Google's library for on-device face, hand, and pose tracking. "Track hands and draw landmarks → hands.html"
TF.js 🧠 TensorFlow.js: machine learning in JavaScript, running in the browser. "Run a TF.js model on webcam frames → tfjs.html"
FDE 🛠️ Forward deployed engineer: an engineer embedded with customers to deliver working solutions. "Write a first-week FDE engagement plan → fde_plan.md"
FHIR 🏥 HL7's modern standard for exchanging healthcare data as resources over REST APIs. "Make a sample FHIR Patient resource → patient.json"
Software Factory 🏭 An automated pipeline in which agents generate, test, and ship software. "Diagram the factory stages → factory.svg"
Daredevil It 😈 Your pattern: reach a runnable result in under five minutes. "Give me a runnable graph from this data now → graph.html"

📁 Favorite Top-10 File Types: Structured vs. Unstructured

# Type Emoji Structure Why it matters Preamble prompt pattern
1 .md 📝 Semi-structured Specs, memory, and slides; humans and AIs both read it well. "Output only Markdown with H2 sections, a table, and a checklist."
2 .html 🌐 Semi-structured (markup) A single-file app that runs in any browser. "Output one self-contained HTML file with inline CSS and JS and no build step."
3 .py 🐍 Structured (code) Data, ML, Streamlit, and automation. "Output one runnable Python file with named regions and a main()."
4 .json 🧾 Structured Configs, tool schemas, and agent cards. "Output valid JSON only, matching this schema: …"
5 .csv 📊 Structured (tabular) Datasets, metrics, and age-group tables. "Output CSV with a header row; columns: …"
6 .yaml ⚙️ Structured Workflows (GitHub Actions) and deployment configs. "Output a valid YAML GitHub Actions workflow that does …"
7 .js 🟨 Structured (code) Browser logic, modules, and Node scripts. "Output an ES module exporting …, with no dependencies."
8 .svg 🖼️ Structured (vector markup) Diagrams and icons that scale and can be edited as text. "Output an SVG diagram, 1200×675, with labeled boxes and arrows."
9 .png 🏞️ Unstructured (raster image) Slide images and screenshots. "Create a 16:9 PNG slide image showing … with no small text."
10 .mp4 🎬 Unstructured (video) Demos and talk clips. "Script a 60-second video: shot list, narration, and captions."

Rule of thumb: use structured files (.json, .csv, .yaml, .py, .js, .svg) when a program consumes the output; use semi-structured files (.md, .html) when both people and AIs consume it; use unstructured files (.png, .mp4) when the audience is human. The general preamble is: Role → Inputs → Constraints → Output file type and name → Acceptance check.

Protocol / Standard Emoji What it is Steward Examples of support (apps / models / platforms)
MCP (Model Context Protocol) 🔌 An open protocol that connects AI apps to tools, resources, and prompts. Introduced by Anthropic (Nov 2024); now an open project Claude apps and Claude Code; OpenAI Agents SDK; GitHub Copilot agent mode in VS Code; Gemini CLI; Microsoft Copilot Studio

WebRTC 📡 Real-time peer-to-peer audio, video, and data in browsers. W3C and IETF Chrome, Edge, Firefox, Safari; PeerJS; OpenAI Realtime API (WebRTC connection option)
Web Speech API 🎙️ Browser speech recognition and speech synthesis. W3C Community Group draft Speech synthesis in all major browsers; recognition in Chromium-based browsers and Safari, with limited support in Firefox
WebGPU 🎮 Modern GPU graphics and compute from the browser. W3C (GPU for the Web WG) Chrome and Edge (since v113), with Safari and Firefox support rolling out; three.js WebGPURenderer; TF.js WebGPU backend
OAuth 2.0 / OpenID Connect + MFA 🔐 Delegated authorization (OAuth) plus identity (OIDC); MFA adds a second factor. IETF (OAuth); OpenID Foundation (OIDC) Microsoft Entra ID; GitHub (2FA required for code contributors); the MCP authorization spec builds on OAuth 2.1
OpenTelemetry 📶 A vendor-neutral standard and SDKs for traces, metrics, and logs. CNCF Azure Monitor / Application Insights; GenAI semantic conventions for LLM spans
HL7 FHIR 🏥 A healthcare data exchange standard built on REST resources (Patient, Observation, and so on). HL7 International Azure Health Data Services (FHIR service); Google Cloud Healthcare API; Epic and Oracle Health FHIR APIs
SMART on FHIR 🩺 OAuth-based launch and authorization for apps running on top of FHIR EHRs. HL7 and SMART Health IT EHR app launch at many U.S. health systems (Epic, Oracle Health)
HL7 v2 📨 A pipe-delimited clinical messaging standard that is still widely used inside hospitals. HL7 International Interface engines; Azure and Google healthcare APIs support ingestion and conversion
Markdown / CommonMark 📝 A plain-text formatting syntax, with CommonMark as its standard specification. CommonMark community GitHub; virtually every LLM chat UI renders Markdown
