### 📁 Favorite Top-10 File Types: Structured vs. Unstructured

| # | Type | Emoji | Structure | Why it matters | Preamble prompt pattern |
|---|---|---|---|---|---|
| 1 | `.md` | 📝 | Semi-structured | Specs, memory, and slides; humans and AIs both read it well. | "Output only Markdown with H2 sections, a table, and a checklist." |
| 2 | `.html` | 🌐 | Semi-structured (markup) | A single-file app that runs in any browser. | "Output one self-contained HTML file with inline CSS and JS and no build step." |
| 3 | `.py` | 🐍 | Structured (code) | Data, ML, Streamlit, and automation. | "Output one runnable Python file with named regions and a `main()`." |
| 4 | `.json` | 🧾 | Structured | Configs, tool schemas, and agent cards. | "Output valid JSON only, matching this schema: …" |
| 5 | `.csv` | 📊 | Structured (tabular) | Datasets, metrics, and age-group tables. | "Output CSV with a header row; columns: …" |
| 6 | `.yaml` | ⚙️ | Structured | Workflows (GitHub Actions) and deployment configs. | "Output a valid YAML GitHub Actions workflow that does …" |
| 7 | `.js` | 🟨 | Structured (code) | Browser logic, modules, and Node scripts. | "Output an ES module exporting …, with no dependencies." |
| 8 | `.svg` | 🖼️ | Structured (vector markup) | Diagrams and icons that scale and can be edited as text. | "Output an SVG diagram, 1200×675, with labeled boxes and arrows." |
| 9 | `.png` | 🏞️ | Unstructured (raster image) | Slide images and screenshots. | "Create a 16:9 PNG slide image showing … with no small text." |
| 10 | `.mp4` | 🎬 | Unstructured (video) | Demos and talk clips. | "Script a 60-second video: shot list, narration, and captions." |

**Rule of thumb:** use structured files (`.json`, `.csv`, `.yaml`, `.py`, `.js`, `.svg`) when a program consumes the output; use semi-structured files (`.md`, `.html`) when both people and AIs consume it; use unstructured files (`.png`, `.mp4`) when the audience is human. The general preamble is: **Role → Inputs → Constraints → Output file type and name → Acceptance check.**
